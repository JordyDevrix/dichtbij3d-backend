# dichtbij3d Backend

This is the backend repository for Dichtbij3D, a Java application built with Maven.

## Tech Stack
- Java
- Maven
- Docker

## Guidelines
- Follow standard Java programming and Maven conventions.
- Ensure all new features are accompanied by appropriate unit tests.
- Maintain the `Dockerfile` and `docker-compose.yml` for backend containerization.
- Ensure dependency additions in `pom.xml` are justified and compatible.
